A modern, responsive, and elegant boutique hotel website developed for **Jee Ri Haveli**.

Designed with premium hospitality-focused UI/UX, immersive visuals, responsive frontend engineering, and smooth user interactions to deliver a luxurious digital experience for visitors and guests.

---

## 🌐 Project Overview

**Jee Ri Haveli** provides an interactive online presence showcasing boutique accommodations, hotel amenities, services, image galleries, and contact details with smooth animations and intuitive navigation.

---

## ✨ Features

- **Fully Responsive Design**: Optimized across mobile, tablet, and desktop screens.
- **Modern Hotel UI/UX**: Premium aesthetic tailored for hospitality and heritage experiences.
- **Accommodations Showcase**: Dedicated rooms and suites presentation.
- **Interactive Image Gallery**: Highlighting property interiors, exteriors, and amenities.
- **Services & Facilities**: Clear overview of hotel offerings and services.
- **Smooth Animations**: Powered by Framer Motion, Swiper.js, and AOS.
- **Direct WhatsApp Integration**: Quick inquiry and instant connectivity for guests.
- **Fast Performance**: Built on Vite with modular React components and Tailwind CSS styling.

---

## 🛠️ Tech Stack

| Technology | Usage |
|------------|-------|
| **React.js (v19)** | Frontend UI Library |
| **Vite** | Build Tool & Dev Server |
| **Tailwind CSS** | Utility-first Styling |

## 📦 Getting Started

### Prerequisites

Ensure you have **Node.js** (v18 or higher) and **npm** installed on your system.

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/nikhil9910/hotel-website-.git
   ```

2. **Navigate to the project directory:**
   ```bash
   cd hotel-website-
   ```

3. **Install dependencies:**
   ```bash
   npm install
   ```

4. **Start the local development server:**
   ```bash
   npm run dev
   ```

5. **Build for production:**
   ```bash
   npm run build
   ```
